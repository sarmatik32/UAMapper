UA Mapper Full

1. Отримайте ключ MapTiler.
2. Замініть PUT_YOUR_KEY_HERE.
3. Покладіть свою PNG іконку як drone.png.
4. Запустіть:
   python -m http.server 8000
5. Відкрийте http://localhost:8000

Функції:
- MapTiler Planet Lite v3
- PNG маркери
- Кілька БПЛА
- Підсвітка тайлів
- Зміна радіусу колесом миші
